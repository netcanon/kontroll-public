# Start here

**Installing kontroll from a release bundle on a fresh Debian VM?**

Follow **[docs/install-from-scratch.md](docs/install-from-scratch.md)** start to finish. It is the
complete, tested path from a stock VM to a working instance: install prerequisites → scaffold your
own private overlay + keys → deploy the stack → onboard your first device through the GUI. No GitHub
account is required — this bundle *is* the code.

Orientation: [README.md](README.md) (what's in the tree) · [PLAN.md](PLAN.md) (architecture + the *why*).

Developers with repo/GitHub access can instead clone and follow [docs/SETUP.md](docs/SETUP.md).
